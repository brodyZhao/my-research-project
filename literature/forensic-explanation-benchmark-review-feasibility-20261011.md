# 图像鉴伪检测器解释可靠性：文献综述与选题可行性分析

日期：2026-10-11。范围：基于本仓库截至今日的文献台账、已核原文及公开论文所做的**范围性综述**。现有检索路线尚未全部闭合，因此本文不声称系统综述或不存在遗漏。本文的“解释可靠性”聚焦两件可分别验证的事：解释所述视觉事实是否成立；检测器的输出是否对自己所述证据表现出有区别的行为依赖。

## 一、研究问题与建议定位

建议将选题限定为：**对能够同时输出鉴伪判决与理由的模型，建立由成对来源图像、可追溯编辑记录、独立证据标注和经验证的反事实干预构成的基准，评估其“自述证据”的事实支持度与判决的行为依赖程度。** 英文工作题目可为 *Do Image Forgery Detectors Use Their Own Explanations? A Benchmark for Claim-Conditioned Evidence Dependence*。

这里测到的是黑盒可观察的“行为依赖”，不能直接还原模型内部的真实推理。对某处修补后分数不变，也不自动证明该解释虚假：模型可能同时利用多个冗余线索，或修补操作没有真正消去目标线索。反之，分数变化也可能来自修补生成的新伪迹。基准应将这些情况单独记录，而非统称“忠实/不忠实”。

## 二、文献脉络：现有研究测到了哪一步

| 路线与代表工作 | 已有贡献 | 与本题的交集及尚存边界 |
| --- | --- | --- |
| 检测、解释与定位联合基准：[FakeBench](https://arxiv.org/html/2404.13306)、[Forensics-Bench](https://openaccess.thecvf.com/content/CVPR2025/papers/Wang_Forensics-Bench_A_Comprehensive_Forgery_Detection_Benchmark_Suite_for_Large_Vision_CVPR_2025_paper.pdf)、[So-Fake](https://arxiv.org/html/2505.18660)、[METER](https://arxiv.org/abs/2507.16206) | 将真假判断、文本线索、局部区域或证据一致性纳入评测，证明只看分类准确率不足。 | 主要衡量答案、文本与区域是否正确或匹配；通常没有对**模型自己提出的证据**进行受控干预，再观察原判决。 |
| 解释事实性及幻觉评测：[FORGE](https://arxiv.org/html/2503.15867)、[TriDF](https://arxiv.org/html/2512.10652)、[XAIGID-RewardBench](https://arxiv.org/html/2511.12363) | 人评或自动规则评估线索具体性、事实支持、空间对应、偏好等。FORGE 使用“faithfulness”一词评价解释与图像事实的对应。 | 其“faithfulness”多指解释的内容真实性；不能据此推断检测器**做判断时**使用了该事实。TriDF 的 CHAIR 还把空映射及部分误判纳入计算，不能将该数值直接解释为纯幻觉率。 |
| 可见伪迹与检测线索对齐：[X-AIGD](https://openreview.net/pdf?id=Tk8ujiOgHM) | 建立人工标注的局部感知伪迹，并检验检测器与可见伪迹的空间关系，是本题最接近的**数据与基准**先行工作之一。 | 感知伪迹的标注与定位不等于解释文本的模型自述证据，也不直接检验“该模型移除所述线索后是否改变判决”。若新工作只做伪迹标注、IoU、文本相似度，将与此类工作高度重叠。 |
| 有定位的解释生成：[EFR](https://arxiv.org/html/2608.08009) | **本题最接近的直接鉴伪系统论文**：面向图文篡改，联合判别、人脸框、文本跨度和证据锚点，训练中加入 anchor–verify/一致性约束。 | EFR 证明可以训练出结构化、接地的解释；其公开评测主要验证正确预测样本的解释及锚点质量，未给出针对每个模型自述证据的独立反事实依赖基准。它应当被列为首要比较对象，而不能略过。 |
| 自述区域的扰动检验：[Hopf 等](https://arxiv.org/html/2605.31192) | 在少量正确分类人脸上比较遮挡解释提及的伪迹区域与未提及区域的效果，已经触及“模型是否依赖自述证据”的核心问题。 | 这是**最接近的实验方法**。公开实验约 50 例，黑色遮挡容易造成分布外输入；尚不是跨模型、跨篡改类型、带编辑有效性门控的标准化基准。不能宣称“无人做过自述证据干预”。 |
| 后验解释有效性：[Kuturin 等](https://arxiv.org/html/2607.29581)、[STeREx-Net](https://www.mdpi.com/2227-7080/14/9/545)、[Baldassarre 等](https://arxiv.org/html/2404.18649) | 测试显著图的删除、保留、随机对照或对抗敏感性；Kuturin 明确说明某些检测器本身使用数据捷径，且扩散修补会制造检测器敏感的痕迹。 | 针对显著图或特定模型的效度检验已存在。本题可新增“自然语言原子理由—区域—判决”的联合评价，但必须把后验热图作为不同赛道。 |
| 跨任务反事实解释评测：[EDCT-Bench](https://arxiv.org/html/2609.17953)、[Menzat 等](https://arxiv.org/abs/2609.06704) | 使用经校验的视觉编辑测试解释与模型答案的一致性，提供可移植的干预设计和重建对照。 | 方法上很接近，但研究任务并非图像鉴伪；也提示“通过行为反驳/支持解释”不能证明内部推理机制。 |

补充背景：[Sanity Checks for Saliency Maps](https://papers.nips.cc/paper/2018/hash/294a8ed24b1ad22ec2e7efea049b8737-Abstract.html)指出解释图可能与模型参数缺乏应有联系；[Wang 等关于删除指标的研究](https://proceedings.mlr.press/v235/wang24br.html)系统讨论了删除指标受分布外扰动影响的问题。它们不是鉴伪基准，但决定了本题的测量效度要求。

### 综合判断

目前的直接重合可以分成三层。**EFR** 与拟评测对象和结构化解释最接近；**Hopf 等**与拟用“自述线索—对照干预—判决响应”的机制最接近；**X-AIGD**与自建可见伪迹数据基准最接近。三者合起来已覆盖构想中的大部分单项元素。因此，论文新意不能写成“首次研究鉴伪解释可靠性”或“首次用反事实检验解释”。更有说服力的贡献是：在一个可复用且有干预有效性门控的鉴伪基准中，同时测量**自述内容的事实性、可定位性、判决依赖、可判定覆盖率**，并用统一协议比较多种解释型检测器。

## 三、基准应怎样定义

### 1. 数据集与动态评测的关系

静态数据集保存“可知的图像事实”，不能预先为所有检测器标出其内部判决原因。建议将交付物设计为**基础成对数据 + 独立标注 + 根据各模型解释生成的动态干预 + 评分代码**。后两项是 benchmark 的必要组成。

基础样本以可精确配准的局部篡改为主：真实源图、篡改图、编辑脚本或可追溯操作日志、编辑掩膜、生成与后处理参数、配对身份。另由不知模型输出的标注者判断“图上有哪些可见线索”，记录区域、线索类型、可信度及“无可确认线索”。**编辑掩膜是篡改真值，不等于所有可见伪迹的真值**；检测器也可能依赖跨区域的频谱、压缩或语义线索。整图合成图、文本证据、视频和“为何为真”的解释应先作独立赛道或后续扩展。

样本应包含正负类、真实困难负例、不同编辑方法、压缩/平台后处理、正确与错误预测。以原始源图为分组单位划分训练/开发/隐藏测试，避免同一来源或近重复图跨集合泄漏；保留版权及使用许可记录。当前局部篡改任务可先选两种有配准来源的操作，不必在第一版囊括所有生成场景。

### 2. 模型与理由的标准化

冻结模型版本、提示词、采样与判决阈值；保存原始真假输出、连续分数（如可用）、完整解释。将解释拆成可检验的**原子视觉主张**，如“左眼边界不自然”“某处文字边缘有拼接痕迹”，并分别标记区域、线索类型、是否可定位、是否可由图像核实。抽取可由模型辅助，但须由盲评者抽样审计并报告一致性。通用 VLM 经提示产生的解释、原生解释检测器和仅输出热图的检测器分别报告，避免不同输出类型被同一指标混排。

每条主张先经过事实支持核查。一个位置准确但内容不真实的主张，或真实但无法定位的全局线索，不能直接进入相同的局部移除实验；需报告其比例和原因。所有模型都应先报告检测能力（平衡准确率、AUROC 或可获得的同等指标），包括误判样本的解释；只在正确样本上算解释分会隐藏最危险的失败。

### 3. 有效性门控后的行为依赖实验

对可定位主张，在篡改图上尝试精确恢复其对应源内容；若有条件，再做源图相同区域的逆向插入。每个测试配套：同面积、同纹理或同位置分布的**非自述区域对照**，随机区域对照，空操作/相同编码对照，完整篡改掩膜恢复正对照。针对可能生成伪迹的修补，人工或独立检测器审查编辑痕迹；检查目标线索确实消失、目标外图像未被明显改变、真假标签按预期维持或转换。把编辑器、随机种子和输出固定下来。

核心量可以定义为自述区域干预造成的连续鉴伪分数变化，减去匹配对照区域的平均变化；并报告方向、置信区间、以源图聚类的变异和各模型可评估样本数。阈值、最小有意义变化及不确定性分析需在测试集评测前定下。**不宜以“未翻转标签”作为唯一不忠实证据**：多条理由可能冗余，单独移除一条不足以翻转；应增加联合移除、多主张交互分析。只提供离散标签的闭源模型单列赛道，以重复查询得到的响应率衡量，不能与连续分数直接同榜。

完整篡改区域恢复的正对照若不能让本应可识别的样本出现预期变化，则该样本的局部必要性测试应标为“不可判定/门控失败”，而非给检测器计零分。公开结果同时报告门控前总样本、理由可抽取率、事实支持率、可定位率、干预有效率与最终可判定率，防止只展示容易成功的子集。

### 4. 建议的结果呈现

不要压成一个“解释可靠性总分”。至少提供四条轴：①鉴伪性能；②自述主张的事实支持与区域质量；③在有效干预样本上的相对行为依赖；④可判定覆盖率。再按篡改类型、正确/错误预测、不同模型输出类型、编辑器和后处理分层。针对“近零效应”，使用预注册等效界限或精度要求，而不把普通不显著检验当作“没有依赖”。

## 四、可行性与主要风险

**结论：有条件可行，但首要风险在测量效度，不在构建图像数量。** 本仓库先前的小规模试验已经提示此点：21 对 FF++ 测试图像中的分类初筛可以通过，但 9 个真实篡改区域恢复样例的正对照没有产生预期的分数间隔；另一个 source-swap 小试验样本不足且缺盲评和预设阈值。这些是**现有实验流程的预警**，不能据此宣布模型解释失真，更不能把当前结果直接包装为正式 benchmark。详见本仓库 `edition3_stage_A3_evidence_utility_protocol.md`、`edition4_stage_A4_counterfactual_resynthesis_protocol.md` 和 `work/experiment_audit_20260928/README.md`。

| 风险 | 对结论的影响 | 可执行的门槛 |
| --- | --- | --- |
| 恢复/修补制造新痕迹，尤其是扩散模型修补 | 响应来自编辑器而非被删除的理由 | 先比较精确源图恢复、不同编辑器、空操作与同编码对照；由盲评核目标线索去除和编辑痕迹。 |
| 篡改掩膜与可见理由不一致，或理由是全局线索 | 局部干预未命中待测证据 | 区分编辑区域、可见伪迹区域和模型自述区域；全局主张单列赛道。 |
| 检测器对该编辑类型本就无感 | “不响应自述区域”不可解释 | 完整篡改恢复及对应插入为正对照；不通过者记不可判定并报告覆盖率。 |
| 只挑正确、易定位解释，或不同模型可评估子集不同 | 排名受选择偏差影响 | 保存全体样本的流水线计数；共同可评估子集与各模型自身可评估子集同时报告。 |
| 标注判断带主观性、LLM 裁判偏差 | “事实支持”评分不稳定 | 双人以上独立盲标、争议裁决，报告一致性与分层错误案例；自动评分须用人评校准。 |
| 查询成本与黑盒接口不一致 | 无法公平计算分数差异 | 先以可导出连续分数的开放模型验证方法；闭源模型另设离散响应率协议。 |

建议用**门控式试点**而非立即扩成大数据集：先选两类有精确源图的局部篡改、少量有原生解释的模型，在几十到一百对独立源图上核查正对照、干预痕迹、标注一致性与分数方差；再据观察方差和预设最小效应做正式样本量规划。若“完整恢复”的正对照仍经常失败，优先重设计数据和操作定义，而不是扩大样本。若门控成功，再扩模型、跨生成器和压缩条件；真实图像的“为何为真”与整图合成可作为后续独立扩展。

## 五、可用于开题的研究问题与贡献边界

1. **RQ1：** 检测器给出的视觉理由中，多少主张可抽取、可核实、事实成立且可定位？这一比例在正确与错误判决中如何变化？
2. **RQ2：** 在干预经验证有效的样本上，移除检测器自述线索对其判决分数的影响，是否大于匹配的非自述区域；冗余线索和联合移除如何改变结果？
3. **RQ3：** 这种相对行为依赖在不同篡改方式、后处理、编辑算子和检测器类别下是否稳定；哪些条件导致结果不可判定？

预期贡献宜表述为：①一套可追溯、可配对且有独立可见线索标注的鉴伪评测数据；②主张级事实核验与有效性门控的反事实评测协议；③多类解释检测器的分层基线及失败案例。暂不承诺“揭示真实内部因果推理”“证明所有解释都是忠实/不忠实”或“首次研究此问题”。训练新检测器或用评测信号修复解释可作为后续论文，当前选题先把 benchmark 做扎实。

**最终选题判断：** 若工作只增加数据并比较解释与标注的相似度，创新空间偏窄且与 X-AIGD、FORGE、TriDF、EFR 相关工作明显重叠；若能把 Hopf 式自述证据干预发展为有正负对照、编辑有效性审查、不可判定率与跨模型统一协议的基准，则仍有清晰研究空间。最关键的第一步不是大规模采集，而是证明小规模试点中“自述区域被有效改变、对照公平、正对照能工作”这三件事。

# 图像鉴伪解释可靠性：选题重合度与研究空间判断（2026-10-11）

## 判断口径

本备忘录依据现有 72/172 文献账本、Stage A/A4 协议与 2026-10-11 对下列原文的定向复核。它是阶段性新颖性判断，不是系统综述或“没有雷同论文”的证明。现有 V2.1 检索和部分全文核读尚未结束。

项目中最具体的研究命题是：对图像鉴伪模型自己声称的、经事实与空间核验的证据区域作有效干预，比较同一模型判决变化与匹配对照、真实伪迹阳性对照；在此基础上判断解释正确性和决策依赖是否错位，并仅在信号有效后检验偏好学习修复。应把事实接地、空间定位、决策依赖、解释稳定性和用户适当依赖分开报告。

## 最接近的工作

| 原文 | 已做的相似工作 | 与当前命题的剩余差别 |
|---|---|---|
| [EFR：Evidence-Grounded Forensic Reasoning（2026）](https://arxiv.org/html/2608.08009) | 在图文篡改检测中用 Anchor-and-Verify 把解释证据绑定到预测的图像框/文本跨度，再以分类、定位和证据—锚点一致性奖励训练模型。与本项目“鉴伪解释的证据接地＋训练修复”在任务、输出结构和优化方向上极为接近，应列为首要直接竞争工作。 | EFR 评的是证据与模型自己预测的锚点是否一致；§4.4 的文字指标只在正确预测的篡改样本上算 NLI、重复度、多样性、ROUGE。原文未呈现对自述证据作图像干预、用真实伪迹阳性对照核验算子、或测量事实正确但无额外决策依赖的发生率。内部一致性不自动等于决策因果忠实性。 |
| [Hopf 等，Specialist-Generalist Fusion（2026）](https://arxiv.org/html/2605.31192) | 对解释点名的伪迹框与匹配人脸对照作遮挡；50 个正确分类案例报告前者造成更大错误；用二分类标签做 rationale tuning。 | 与“自述区域 vs 匹配区域”的局部因果诊断高度重合。仅正确案例、脸部区域、黑块遮挡；未单独验证错误预测时的文字事实/GT 阳性对照、非 OOD 编辑算子、等效检验与用户依赖。不可再把“首次做自述区域干预”作为创新。 |
| [Kuturin 等，Explaining AI-Image Detection（2026）](https://arxiv.org/html/2607.29581) | 检验检测器热图是否超过不读模型的控制，并做局部删除、编码历史和数据捷径控制。作者明确说通过控制不等于证明完整忠实性。 | 热图而非自由文本自述证据；但干预效度、平凡对照和编码捷径的框架与本项目高度相近。特别指出扩散 inpainting 会注入检测器可能识别的生成痕迹，直接挑战 A4 算子。 |
| [Ding 等，EDCT-Bench（2026）](https://arxiv.org/html/2609.17953) | 从 VLM 自身自然语言解释抽取视觉概念，生成并核验反事实编辑，再比较答案和解释一致性；还尝试用反事实样本训练。 | 概念与“从自述证据出发的干预＋训练”高度重合，任务是 VQA/驾驶/空间推理而非鉴伪；其作者也明确限定为行为一致性测试，不恢复内部因果机制。 |
| [Menzat 等，Counterfactual Tests for CoT Faithfulness（2026）](https://arxiv.org/abs/2609.06704) | 删除视觉对象、做重建对照，检验答案概率变化是否与 CoT 提及对象一致。 | 跨域 VLM 方法非常接近；未处理鉴伪伪迹、局部真伪语义和新生成痕迹。 |
| [Gowrisankar 等（2024）](https://arxiv.org/abs/2312.06627)、[Baldassarre 等（2024）](https://arxiv.org/html/2404.18649) | 已用对抗扰动/高权重区域测试 deepfake 检测解释的评价效度和判决敏感性。 | 证明“鉴伪解释的因果/扰动评价”不是新题；主要比较热图或解释算法，不覆盖经事实核验的自由文本 claim 与同模型的完整证据链。 |
| [FORGE（2026）](https://arxiv.org/html/2503.15867)、[FKG（2026）](https://arxiv.org/html/2606.23917) | 已有人评、claim/区域事实核验、解释完整性及信任评分。 | 事实正确性与信任构念也不新；前者没有严格自述区域干预，后者的信任升高不能证明适当依赖。 |

## 可成立的研究空间与前提

1. **构念拆分后的错位发生率**：把“区域/视觉主张正确”与“模型判决对其有特异依赖”交叉成四格，在正确与错误判决、局部篡改与整图生成、不同模型和数据域上估计发生率与不确定性。现有邻近工作通常仅测其中一边或限定正确案例。
2. **鉴伪专用干预效度**：事先证明编辑主要移除目标伪迹且不引入可检测的新伪迹；用真实伪迹阳性对照、等面积语义匹配对照、随机/中心先验、同轮原图及多算子敏感性分析。若阳性对照或两类判别力不通过，主命题不可识别。
3. **独立下游效用**：若考虑偏好学习，使用外部人工核验、跨域测试、错误案例和无需生成解释的检测指标评价；随机偏好对与仅标签训练作为必要基线。若做人因，测有错与无错建议时的恰当采纳，而非信任评分本身。

当前最有价值的定位是“图像鉴伪自由文本解释的事实正确性与判决依赖是否脱钩，以及如何可靠地测量”，而不是笼统的“可靠解释模型”。若把主要贡献写成证据与预测框/文本跨度对齐并以一致性奖励优化，则与 EFR 高度重合；应将 EFR 设为首要直接基线，把外部事实核验、受控干预和失败样本覆盖写成可复核的区别。A4 的 SDXL inpainting 方案尚不能因控制区差分就被视为有效：生成痕迹可能随区域语义和纹理而变，不能假定在 claimed 与 control 中同量。项目历史实验还存在单类 Gate 0、GT 局部阳性对照反向和缺少盲法 grounding，详见 `work/experiment_audit_20260928/README.md`。因此现阶段不能宣称已发现错位现象或证明偏好学习有效。

## 未决

- DDL、Side-VLM 等付费全文的 faithfulness 操作定义尚未核实；V2.1 检索有未闭合路线。因此“没有雷同”只能表述为截至本次可核原文尚未发现完全相同的完整组合。
- 若论文只做“遮挡自述框导致判决下降”或“用反事实挑偏好对并训练”，与 Hopf 等、EDCT 等高度重合，独立贡献不足。必须先解决鉴伪编辑算子与构念效度，再决定是否扩大为训练论文。
